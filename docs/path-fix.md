# Исправление запуска Telegram Widget

Исправляет завершение локальной службы с кодом 1 при запуске из OBS.
Причина: OBS возвращает относительные пути, которые раньше неправильно разрешались
после изменения рабочей папки дочернего процесса (`obs-studio/data/data/...`).
Теперь пути преобразуются в абсолютные до запуска Node.js.

Для уже установленного плагина:

1. Полностью закройте OBS.
2. Скопируйте `telegram-widget.dll` из `obs-plugins/64bit` этого архива в
   `C:\Program Files\obs-studio\obs-plugins\64bit` с заменой старого файла.
3. Запустите OBS и откройте док-панель Telegram Widget.

Остальные файлы, настройки и источники менять не нужно.
Не переносите папки в дополнительный каталог `data/data`.

Проверки: 19 тестов службы и виджета, отдельный нативный тест QProcess
с относительным путём OBS, сменой рабочей папки, пробелами и кириллицей.
Полный показ виджета в рабочей OBS после замены DLL проверяется отдельно.
